Icon-only button for toolbars, close buttons, and table row actions. Default `subtle` variant keeps it quiet until hover. Pair with a Tabler icon glyph.

```jsx
<IconButton aria-label="Settings"><i className="ti ti-settings" /></IconButton>
<IconButton variant="light" color="error" aria-label="Delete"><i className="ti ti-trash" /></IconButton>
```

Variants: filled/light/subtle. `radius` pill (default), md, or sm.
